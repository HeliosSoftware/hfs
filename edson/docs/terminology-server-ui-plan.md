# Helios Terminology Server – Plan

## Immediate Features (Enable Now)
- **[Partial Match Search](ca://s?q=Enable_partial_match_search)**  
  - Support searching by title and name with partial matches.  

- **[Code Search with Mappings](ca://s?q=Code_search_with_mappings)**  
 
  - Show additional relationships such as **[maps to](ca://s?q=Show_maps_to_relationships)** and **[subsumes](ca://s?q=Show_subsumes_relationships)**.  


## Deferred Features (Future)

- **[Relationship Display](ca://s?q=Show_relationships_in_UI)**  
  - Present relationships in a structured “form shape” view:  
    - Usage in other value sets  
    - Parent concepts  
    - Child concepts  

- **[Graph Diagram Representation](ca://s?q=Graph_diagram_representation)**  
  - Visualize relationships (parents, children, mappings, usage) in an interactive graph diagram.  

- **[ECL Query Support](ca://s?q=ECL_query_support)**  
  - Add advanced query capabilities using Expression Constraint Language (ECL).  

- **[Other Relationships](ca://s?q=Defer_other_relationships)**  
  - Defer display of additional relationship types beyond maps to, subsumes, parents, children, and usage in value sets.  


- **[Developer Endpoint Page](ca://s?q=Add_OpenAPI_endpoint_page)**  
  - Add an OpenAPI-style endpoint page for developers.  
  - Include examples for terminology server queries and responses.  
---

### Summary
- **Now:** Improve usability with partial match search, code search + mappings (including maps to and subsumes), relationship visualization, developer-friendly OpenAPI endpoint documentation, and alignment of code system seeds with HSF.  
- **Future:** Enhance with graph-based visualization, advanced ECL queries, and extended relationship types.
