# M2 - Search Routing, Sync Semantics, Idempotency

## Goal
Guarantee that `s3-elasticsearch` behaves as true polyglot persistence: S3 is canonical storage, Elasticsearch is authoritative for all search execution.

## Implemented Tasks

1. Force S3-primary search routing to Elasticsearch.
- Files:
  - `crates/persistence/src/composite/storage.rs`
- Purpose:
  - Ensure `execute_routed_search`, primary search fallback, and `search_count` never attempt S3 search execution in `s3-elasticsearch` mode.
- Tests:
  - `crates/persistence/tests/composite_s3_elasticsearch_tests.rs`

2. Harden sync observability for secondary propagation.
- Files:
  - `crates/persistence/src/composite/storage.rs`
  - `crates/persistence/src/composite/sync.rs`
- Purpose:
  - Evaluate per-backend sync outcomes and emit metadata-rich failure logs (tenant/resource/version/backend).

3. Add version-aware, idempotent ES indexing behavior.
- Files:
  - `crates/persistence/src/composite/sync.rs`
  - `crates/persistence/src/backends/elasticsearch/storage.rs`
- Purpose:
  - Carry version metadata through sync events.
  - Inject `meta.versionId` into indexed resources.
  - Ignore stale or duplicate replay events.
- Tests:
  - `crates/persistence/tests/elasticsearch_tests.rs`
  - sync unit tests in `crates/persistence/src/composite/sync.rs`

4. Make delete propagation idempotent.
- Files:
  - `crates/persistence/src/composite/sync.rs`
  - `crates/persistence/src/backends/elasticsearch/storage.rs`
- Purpose:
  - Treat missing ES docs during delete replay as converged success.

5. Align tenant index naming safety.
- Files:
  - `crates/persistence/src/backends/elasticsearch/backend.rs`
  - `crates/persistence/tests/elasticsearch_tests.rs`
- Purpose:
  - Sanitize tenant/resource segments in ES index names while preserving tenant filtering behavior.

## Validation
- `cargo test -p helios-persistence --features s3,elasticsearch --test composite_s3_elasticsearch_tests`
- `cargo test -p helios-persistence --features s3,elasticsearch --test elasticsearch_tests -- --skip es_integration`
- `cargo test -p helios-persistence --features s3,elasticsearch test_sync_`
