Figures that are here follow themselves the same way (#1078): every few seconds while they are still moving — counted from recent writes and not yet reconciled, or with an import running (data-dash-moving) — and slower once they settle, so a tab opened before an import starts still notices it. The region is the `dash_live` block and the chart card inside it the `chart_card` block: an htmx request whose HX-Target is `dash-live` or `dash-chart` gets just that block back, anything else (plain navigation, history restore) the whole page. A settled tick may send `state` (the data-dash-state it shows); when the figures are unchanged the server answers 204 and nothing is swapped. The tick also sends what the user has open as `open=pick,table`, and the render keeps it: an open type picker comes back `open hx-preserve` (the very node stays, mid-use), an open table `open`. The type picker's options re-request the chart card through htmx (#555, #599), always rendered open, and the server pushes that selection's own link (HX-Push-Url). hx-sync lets a picker click abort a tick in flight and drops a tick while a click is. A waiting page whose provider did answer (still seeding the tenant, #1078) keeps a slow watch once its fast retries are spent (data-dash-waiting), so it still picks up its figures; the cache's own cold state does not.
