# Getting Started

Choose the path that fits your use case:

- **[Installation](installation.md)** — build from source or download a release binary
- **[Quick Start](quick-start.md)** — run the server and tools with pre-built binaries
- **[Docker](docker.md)** — pull a pre-built image and run in a container

If you just want to try things out with zero setup, the [Docker](docker.md) path is the fastest route.
