# Roadmap

See [ROADMAP.md](https://github.com/HeliosSoftware/hfs/blob/main/ROADMAP.md) in the repository for the current development priorities and planned features.

The roadmap is organized into four sections:

- **Shipped** — features that have landed
- **Now** — actively in design or development
- **Next** — planned for an upcoming cycle
- **Later** — longer-term ideas

Community input is welcome. Join the discussion in [GitHub Issues](https://github.com/HeliosSoftware/hfs/issues) or open a new issue to propose a feature.
