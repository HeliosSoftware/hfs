# Helios FHIR Server — Documentation Site

This directory contains the [mdBook](https://rust-lang.github.io/mdBook/) source for the HFS documentation site.

## Prerequisites

Install mdBook:

```bash
cargo install mdbook
```

## Local development

```bash
# Serve with live reload (open http://localhost:3000)
mdbook serve

# Build once into book/book/
mdbook build
```

The built output (`book/`) is git-ignored and generated by CI on deploy.

## Structure

```
book/
├── book.toml       # mdBook configuration
├── src/            # Markdown source files
│   ├── SUMMARY.md  # Table of contents (controls chapter order)
│   └── *.md        # Chapter and appendix files
└── book/           # Generated output (git-ignored)
```

Adding a new page: create a `.md` file under `src/` and add an entry to `src/SUMMARY.md`.

## Deployment

The site is deployed to GitHub Pages automatically when changes to `book/src/` or `book/book.toml` are pushed to `main`. The site is served at `https://heliossoftware.github.io/hfs/`.
